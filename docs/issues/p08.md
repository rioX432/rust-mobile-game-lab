接続/参加/コマンド/状態受信/再接続。UIやゲーム規則をOS別に複製しない。

## 受入条件

- [ ] 途中参加と切断再接続で最新スナップショットと世代に戻る
- [ ] 古いスナップショット/旧ラウンド入力が再適用されない
